# Password Vault 0.2

Локальный менеджер логинов и паролей с графическим интерфейсом на Tkinter для Windows, macOS и Linux. Данные хранятся только на вашем компьютере: нет облачной синхронизации, аккаунтов и сетевых запросов.

> **Важно.** Это самостоятельный учебный проект, а не коммерческий менеджер паролей, прошедший внешний аудит. Для критичных рабочих секретов и общего доступа команды лучше использовать проверенное решение, например Bitwarden или 1Password.

## Возможности

- Светлый интерфейс с боковым меню: «Все записи», «Избранное», категории.
- Шесть стандартных категорий и пользовательские категории (до 40 символов).
- Поиск по названию, логину, URL и категории.
- Добавление, изменение и удаление записей. Поля: название, логин, пароль, URL, заметка, категория, избранное.
- Генератор паролей на 20 символов: строчные и заглавные буквы, цифры и спецсимволы, по одному символу каждой группы гарантированно.
- Копирование логина и пароля; буфер обмена очищается через 10–60 секунд.
- Кнопка «Открыть» запускает URL записи в браузере.
- Автоблокировка после 1, 3, 5, 10, 15 или 30 минут бездействия и ручная блокировка.
- Смена мастер-пароля с перешифрованием всех записей.
- Зашифрованная резервная копия (`.pvbackup`) и восстановление из неё.

## Быстрый старт

Нужны **Python 3.11+** и Tkinter. Tkinter входит в установщики Python с python.org; в Linux его иногда ставят отдельно, например `sudo apt install python3-tk`.

**Windows (PowerShell):**

```powershell
py -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

**macOS / Linux:**

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

При первом запуске приложение попросит придумать мастер-пароль длиной не менее **12 символов**. Восстановить забытый мастер-пароль нельзя: без него данные не расшифровать.

### Где хранится база

| ОС      | Путь                                                    |
|---------|---------------------------------------------------------|
| Windows | `%APPDATA%\PasswordVault02\vault.db`                    |
| macOS   | `~/Library/Application Support/PasswordVault02/vault.db` |
| Linux   | `$XDG_DATA_HOME/PasswordVault02/vault.db` (по умолчанию `~/.local/share/...`) |

Чтобы начать с чистого хранилища, закройте приложение и удалите (или переместите) `vault.db`.

## Безопасность

**Шифрование**

- Ключ выводится из мастер-пароля через **Argon2id** (64 MiB памяти, 3 итерации, 4 линии, 16-байтовая случайная соль).
- Каждая запись целиком сериализуется в JSON и шифруется **AES-256-GCM** со своим случайным 96-битным nonce.
- Название, логин, пароль, URL, заметка, категория записи и флаг «избранное» хранятся только в зашифрованном виде.
- Мастер-пароль в базу не записывается. Правильность пароля проверяется расшифровкой контрольного значения.
- Смена мастер-пароля проверяет текущий пароль, генерирует новую соль и перешифровывает все записи в одной транзакции.

**Что не шифруется**

- Названия категорий в боковом меню, включая пользовательские (таблица `categories`).
- Настройки автоблокировки и очистки буфера (таблица `preferences`).
- Количество записей и даты их создания и изменения.

Не используйте в названиях категорий информацию, которую хотите скрыть.

**Ограничения**

- Пока хранилище разблокировано, ключ находится в памяти процесса.
- Очистка буфера обмена срабатывает, только если в буфере всё ещё лежит скопированное значение. Менеджеры истории буфера ОС могут сохранить его копию.

## Резервные копии

В боковом меню нажмите **Резервная копия**:

- **Да** — создать файл `.pvbackup`;
- **Нет** — восстановить данные из выбранного файла;
- **Отмена** — закрыть окно.

Резервная копия — это копия зашифрованной базы. Её открывает мастер-пароль, который действовал **в момент создания копии**. Если после этого вы меняли пароль, при восстановлении укажите старый.

При восстановлении все текущие записи и категории **заменяются** данными из копии, и восстановленные записи шифруются действующим мастер-паролем. Перед восстановлением сделайте свежую копию текущей базы.

## Сборка `.exe` для Windows

В PowerShell из папки проекта выполните:

```powershell
powershell -ExecutionPolicy Bypass -File .\build_windows.ps1
```

Скрипт создаст `.venv`, установит зависимости и PyInstaller и соберёт один файл без консоли: `dist\PasswordVault.exe`.

## Структура проекта

```
app.py                    # Интерфейс на Tkinter: экраны, диалоги, автоблокировка, буфер обмена
vault_core.py             # Ядро: SQLite-хранилище, Argon2id, AES-GCM, бэкап и восстановление
tests/test_vault_core.py  # Модульные тесты ядра
build_windows.ps1         # Сборка Windows-исполняемого файла через PyInstaller
requirements.txt          # Зависимости (cryptography)
```

Ядро `vault_core.VaultStore` не зависит от интерфейса и подходит для использования в скриптах или тестах.

```python
from vault_core import VaultStore

store = VaultStore("demo.db")
store.setup_master_password("correct horse battery")
store.add_entry({"title": "GitHub", "username": "me", "password": "s3cret"})
print(store.list_entries())
store.lock()
```

## Тесты

```bash
python -m unittest discover -s tests -v
```

Тесты проверяют CRUD и отсутствие открытого текста в базе, блокировку и разблокировку, смену мастер-пароля, бэкап и восстановление после смены пароля, а также генератор паролей.
