# Password Vault 0.2

Локальный менеджер логинов и паролей для Windows, macOS и Linux. Облачной синхронизации и передачи данных в интернет нет.

## Что реализовано

- современный светлый интерфейс с боковым меню;
- категории и пользовательские категории;
- поиск и избранное;
- добавление, изменение и удаление записей;
- генератор паролей;
- копирование логина и пароля с автоочисткой буфера;
- автоблокировка после 1–30 минут бездействия;
- ручная блокировка;
- безопасная смена мастер-пароля с перешифрованием всех записей;
- зашифрованный backup и восстановление;
- локальная SQLite-база.

## Безопасность

- ключ получается из мастер-пароля через **Argon2id**;
- параметры по умолчанию: 64 MiB памяти, 3 итерации, 4 линии;
- каждая запись полностью шифруется через **AES-256-GCM** с отдельным случайным nonce;
- название, логин, пароль, URL, заметка и категория не хранятся открытым текстом;
- мастер-пароль не записывается в базу;
- смена мастер-пароля выполняется одной транзакцией;
- `.pvbackup` является копией зашифрованной базы и открывается мастер-паролем, действовавшим в момент создания копии.

> Важно: это самостоятельный локальный проект, а не прошедший внешний аудит коммерческий менеджер паролей. Для критичных рабочих секретов и общего доступа команды безопаснее использовать проверенное решение вроде Bitwarden Organization или 1Password Business.

## Запуск

Требуется Python 3.11+.

```powershell
py -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

На Linux/macOS активация окружения:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

Рабочая база создаётся автоматически:

- Windows: `%APPDATA%\PasswordVault02\vault.db`
- macOS: `~/Library/Application Support/PasswordVault02/vault.db`
- Linux: `~/.local/share/PasswordVault02/vault.db`

## Сборка `.exe` для Windows

Откройте PowerShell в папке проекта и выполните:

```powershell
powershell -ExecutionPolicy Bypass -File .\build_windows.ps1
```

Результат: `dist\PasswordVault.exe`.

## Backup

В боковом меню нажмите **Резервная копия**:

- **Да** — создать файл `.pvbackup`;
- **Нет** — восстановить данные из выбранного файла.

При восстановлении текущие записи заменяются. Если после создания копии мастер-пароль менялся, укажите старый пароль, которым защищена копия. Восстановленные записи автоматически шифруются действующим мастер-паролем.
